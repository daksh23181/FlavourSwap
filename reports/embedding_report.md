# FlavorSwap - Deliverable 2 embedding report

Generated by `src/train_embeddings.py`.

## Set-up
- Corpus: Food.com recipes with >= 2 vocabulary ingredients; each recipe is one sentence.
- Window 50 (> longest recipe) with `shrink_windows=False`: every co-ingredient is context, ingredient order is irrelevant.
- 30 epochs, 10 negative samples, seed 42, single worker, deterministic hash (bit-for-bit reproducible).
- Model selection metric: **food-group coherence@10** - share of an ingredient's 10 nearest neighbours (cosine) in the same food group, over 1154 ingredients with >= 50 recipes whose group comes from USDA/Ahn categories (not name keywords). Substitution pairs are not used here, keeping Deliverable 3's Hit@k evaluation unbiased.
